# Mage

*선술집에 마법사가 찾아왔다.* **Mage**는 실리태번 채팅에 **마법 사건**을 심는 확장이에요. 누가·왜·언제 걸었는지까지 정하면, AI가 잊지 않게 매 턴 몰래 알려 줘요.

[English](README.md)

채팅에 "고양이가 됐다"라고만 써도 AI는 변신을 해 줘요. 하지만 몇 턴 지나면 잊어버리죠. Mage는 AI가 혼자서는 못 하는 일을 맡아요.

- **까먹지 않게 붙잡기**: 매 턴 지금 모습, 남은 턴, 할 수 있는 것과 못 하는 것을 몰래 알려 줘요.
- **몸이 바뀌면 할 수 있는 것도 바뀜**: 손바닥만 해지면 문을 못 열고, 거북이는 빨리 못 뛰어요.
- **숫자 관리**: 지속 턴, 저주 단계, 확률은 확장이 세고 AI에게는 결과만 보내요.
- **개연성**: 원인을 정해 두고 매 턴 같이 보내서, AI가 원인을 멋대로 바꾸지 않아요.

## 주문

| 주문 | 계열 | 능력 |
|---|---|---|
| **Polymorph** | 변화 | 다른 생물로 변신해요. 고양이·강아지·여우·토끼·양·거북이·부엉이·새 중에서 고르거나, 형태를 직접 적으면 AI가 할 수 있는 것을 채워 줘요. 🎲로 무작위로 뽑을 수도 있어요(전체에서, 또는 체크해 둔 것 중에서만). |
| **Titan** | 변화 | 몸이 두 배쯤 커져요. 모양은 그대로예요. |
| **Mite** | 변화 | 몸이 손바닥만 해져요. 모양은 그대로예요. |
| **Levitate** | 변화 | 몸이 둥둥 떠요. 높은 곳은 쉽지만 물건 잡기는 힘들어요. |
| **Truth** | 정신 | 거짓말을 못 해요. |
| **Reverse** | 정신 | 하는 말이 전부 반대로 나와요. |
| **Charm** | 정신 | 주변 사람들이 잘해 주고 싶어 해요. |
| **Fear** | 정신 | 겁에 질려 피하거나 도망쳐요. |
| **Sleep** | 정신 | 깊이 잠들어요. **⏰ 깨움** 버튼으로 풀려요. |
| **Glamour** | 환영·시야 | 겉모습만 바뀌어요("어떻게 보일지" 입력). 진짜 변신이 아니라 들킬 수 있어요. |
| **Invisibility** | 환영·시야 | 완전히 안 보여요(소리·발자국·냄새도 없음). **✋ 건드림** 버튼으로 바로 풀려요. |
| **Luck / Jinx** | 운명 | 한동안 일이 잘 풀려요. 방향을 바꾸면 계속 꼬여요. |
| **Dispel** | 보호·해제 | 걸린 효과 하나, 또는 한 계열을 모두 없애요. |

**중첩형 저주**: 조건(예: "💧 물에 닿음")이 맞을 때마다 귀 → 꼬리 → 말 못 함 → 완전 변이 순서로 한 단계씩 진행해요.

## 쓰는 법

1. 마법봉 메뉴(또는 확장 설정)에서 **Mage**를 열어요.
2. **걸기**: *누구에게 / 무엇을 / 얼마나*를 골라요. **자세히**를 열면 누가 걸었는지, 왜, 언제(즉시·몇 턴 뒤·턴마다 확률·조건), 어떻게 풀리는지, 누가 아는지도 정할 수 있어요.
3. **🎲 원인**을 누르면 AI가 최근 대화와 엮어서 원인을 지어 줘요. 먼저 보여 주고, 마음에 들 때만 적용해요.
4. **입력칸 위 상태 줄**에 걸린 효과가 떠요. 이야기 속에서 조건이 일어나면 그 버튼을 눌러요. 잘못 눌렀으면 **↶**로 되돌려요. 칩에는 대상의 프로필 그림(캐릭터 카드·페르소나 그림)이 뜨고, 둘에게 함께 건 주문은 칩 하나에 두 그림이 겹쳐 보여요.
5. **⌃**를 누르면 상태창이 열려요. 제목 줄을 잡고 옮길 수 있고, 접을 수 있고, 옮긴 위치를 기억해요.

### 턴·다시 뽑기·삭제

- 1턴 = 내 메시지 하나 + AI 답변 하나
- 조건 버튼을 누르면 그때의 마지막 메시지에 묶여요. 그 메시지를 **지우거나 다시 뽑으면(스와이프)** 판정이 취소돼요.
- 남은 턴은 늘 지금 채팅을 보고 다시 세요. 그래서 다시 뽑아도 턴이 두 번 깎이지 않아요.
- 아직 발동하지 않은 주문은 AI에게 알리지 않아요(스포일러 방지).

### 누가 풀 수 있나

- **내가 건 마법**(자세히의 "건 쪽" = **나**)만 Dispel할 수 있어요. 정체불명·물건·장소·장난꾼이 건 마법은 Dispel 버튼이 없고, 정해 둔 방법(남은 턴·진실 말하기·특정 행동)으로만 풀려요.
- AI에게도 "글로 풀렸다고 해도 안 풀린다"고 알려요(설정 **저주는 정해진 방법으로만 풀림**, 기본 켜짐).
- 급할 때는 카드의 **⋯** 메뉴 → **강제로 지우기 (없던 일)**. 효과를 지우고 AI에게는 아무것도 알리지 않아요.

### 마법 규칙 (선택)

기본은 꺼짐이라 지금처럼 자유롭게 걸어요. 설정에서 **마법 규칙**을 켜면 *내가* 건 주문에 아래 규칙이 붙어요(남이 건 마법은 공짜지만 내가 못 풀어요).

- **마나**: 최대 10(바꿀 수 있음), 턴마다 +1. 비용: 변화 3 · 정신 2 · 환영 2 · 운명 2 · Dispel 2, 무기한이면 +2. 상태 줄에 `◆ 7/10`으로 보여요.
- **쿨다운**: 내가 건 주문은 3턴, Dispel은 2턴 쉬어요.
- **Loadout**: 채팅마다 주문을 6개까지(바꿀 수 있음) 들고 가요. 나중에 새로 넣은 주문은 3턴 쉰 뒤에 써요.
- **Reload ↻**: 채팅마다 1번, 마나를 가득 채우고 쿨다운을 초기화해요. 20턴마다 다시 생겨요.

마나·쿨다운·Reload도 지금 채팅을 보고 다시 계산해요. 그래서 메시지를 지우거나 다시 뽑으면 같이 되돌아가요.

### AI 판정

AI 답변이 끝날 때마다 짧은 요청을 하나 따로 보내서, 가장 최근 대화에서 조건이 이뤄졌는지(진실을 말함, 깨움, 저주 조건 등) 물어봐요. 판정할 게 있을 때만 물어보고, 없으면 요청도 없어요.

- **제안**(기본): 조건 버튼에 **?**가 붙고 상태 줄에 **✦ n** 버튼이 생겨요. 누르면 AI가 본 근거가 나오고, **적용** 또는 **아니에요**를 골라요.
- **자동**: 바로 적용하고 알림만 띄워요. **↶**로 되돌릴 수 있어요.
- **끄기**: 지금처럼 내가 버튼을 눌러요.

글에서 주문이 "풀렸다"고 하면 그것도 알아채요. 내가 건 주문이면 **Dispel**을 제안하고, 남이 건 주문이면 정해진 방법이 아니라서 안 풀린다고 알려 줘요.

제안은 그 답변에 묶여 있어요. 그 답변을 다시 뽑거나 지우면 제안도 사라져요.

### 설정

- **스킨**: 기본(테마 따라가기) / 고서 / 저주서. 버튼 위치와 기능은 모두 같아요.
- **이 세계의 마법**: 흔함(덤덤하게 반응) / 드묾(놀라고 당황함) / 없음(이상한 일로 그려요).
- 🎲 원인·"채우기"에 쓸 **연결 프로필**(비워 두면 지금 쓰는 API)
- **마법 규칙**, 최대 마나, Loadout 개수, **저주는 정해진 방법으로만 풀림**
- **AI 판정**: 판정 모드(끄기 / 제안 / 자동), **글로 "풀렸다"고 하면 알려 주기**, 점검에 쓸 연결 프로필(기본: 🎲 원인과 같은 프로필), 점검이 읽을 최근 메시지 수(4)
- 언어(English / 한국어), 무작위 형태 범위, 상태창 위치 초기화, 백업 내보내기·가져오기

AI에게는 늘 영어로 짧게(효과 하나에 1~2줄) 보내요. 답변은 원래 쓰던 언어로 나와요. 효과는 한 번에 4개까지 걸 수 있어요.

## 알려진 한계

- AI가 가끔 효과를 무시하거나 너무 길게 설명할 수 있어요. 그래서 지시문을 짧고 분명하게 써요.
- AI 판정은 틀릴 수 있어요. 그래서 기본은 내가 확인하는 "제안"이에요. 점검할 때마다 짧은 요청이 하나 더 나가요.
